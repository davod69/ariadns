# ariadns

فارسی · [English](README.md)

یک سرور **SmartDNS و رله SNI** با قابلیت اجرا روی سرور شخصی، در یک فایل اجرایی Go (فقط با کتابخانه‌ی استاندارد).
DNS کلاینت را روی سرور خودتان بگذارید؛ دامنه‌هایی که انتخاب کرده‌اید (بازی‌ها، ابزارهای هوش مصنوعی، رجیستری‌های توسعه‌دهنده و...) از طریق سرور شما عبور می‌کنند و بقیه‌ی دامنه‌ها عادی حل می‌شوند. پنل مدیریت وب با آدرس مخفی، کاربران با IP و حجم و انقضا، و منوی ترمینالی دارد.

## نصب (لینوکس با systemd)
```bash
curl -fsSL https://raw.githubusercontent.com/davod69/ariadns/main/scripts/install.sh | sudo bash
```
نصب‌کننده باینری را دانلود می‌کند (با بررسی چک‌سام)، IP عمومی را تشخیص می‌دهد، پورت ۵۳ را از `systemd-resolved` آزاد می‌کند، سرویس را بالا می‌آورد و **آدرس پنل و رمز را فقط یک‌بار** نشان می‌دهد. برای آپدیت همین دستور را دوباره بزنید (تنظیمات و داده حفظ می‌شود). پورت‌های `53` (udp و tcp)، `80`، `443` و `8080` را در فایروال سرویس‌دهنده باز کنید.

بعد از نصب، دستور **`adns`** منوی ترمینالی را باز می‌کند.

## چطور کار می‌کند
۱. کلاینت آدرس `store.steampowered.com` را از سرور شما می‌پرسد.
۲. دامنه در یکی از دسته‌های فعال است، پس جواب **IP سرور شما** است.
۳. کلاینت به سرور شما روی ۴۴۳ یا ۸۰ وصل می‌شود. رله فقط SNI (یا Host در HTTP) را می‌خواند، به سایت اصلی وصل می‌شود و بایت‌ها را رد و بدل می‌کند. **TLS هرگز باز نمی‌شود** و سرور نمی‌تواند ترافیک را بخواند.
۴. بقیه‌ی دامنه‌ها با آپ‌استریم رمزنگاری‌شده (DoT) و کش حل می‌شوند.

امنیت: کلاینت ناشناس رد می‌شود (لیست سفید)، رله فقط برای دامنه‌های لیست شما کار می‌کند (پروکسی باز نیست)، مقصدهای خصوصی و loopback بسته‌اند، و پنل زیر یک مسیر مخفی تصادفی با قفل ورود است.

## قابلیت‌ها
- **روتینگ هوشمند:** ۹ دسته‌ی آماده (پلتفرم بازی، بازی آنلاین، ضدتقلب، هوش مصنوعی، ابزار توسعه، استریم، شبکه‌های اجتماعی، بازی ابری، دانلودهای حجیم) و دامنه‌ی دلخواه
- **رله SNI:** لایه‌ی ۴، بدون باز کردن TLS، تکه‌تکه کردن ClientHello (اختیاری)
- **کاربران:** هر کاربر یک IP، سقف حجم، انقضا، و لینک شخصی `/sub/<token>` که کاربر با یک کلیک IP فعلی‌اش را ثبت می‌کند
- **پنل مدیریت:** مسیر مخفی، رمز با PBKDF2، آمار زنده
- **منوی ترمینال:** `adns` (وضعیت، کاربران، دسته‌ها، IP عمومی، ریست رمز، ری‌استارت، لاگ، آپدیت، حذف)
- **سرور DNS:** UDP/TCP/DoT/DoH، کش، بلاک‌لیست، هاست محلی، محدودیت نرخ، متریک Prometheus

## تنظیمات و ساخت
فایل `/etc/ariadns/config.json` (نمونه: `config.example.json`) و داده‌ها در `/var/lib/ariadns`. برای ساخت: `make build` و برای تست: `make test`.

## استفاده‌ی مسئولانه
فقط روی سرور و شبکه‌ای استفاده کنید که اجازه‌اش را دارید و شرایط سرویس‌هایی که از طریق آن به آن‌ها وصل می‌شوید را رعایت کنید.
