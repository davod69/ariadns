# ariadns

فارسی · [English](README.md)

یک سرور DNS سریع و تک‌فایلی به زبان Go (فقط با کتابخانه‌ی استاندارد، بدون وابستگی خارجی).

## قابلیت‌ها
- **پروتکل‌ها:** UDP/TCP روی پورت ۵۳، DNS-over-TLS (پورت ۸۵۳) و DNS-over-HTTPS
- **آپ‌استریم:** ساده یا DoT؛ راهبردهای `fastest`، `race` و `failover`
- **کش:** LRU شارد‌شده، کش منفی، serve-stale و ادغام درخواست‌های تکراری
- **قوانین:** بلاک‌لیست، استثنا (allow)، هاست‌های محلی، فوروارد بر اساس زون
- **کنترل دسترسی:** فقط IPهای مجاز (CIDR) و محدودیت نرخ برای هر کلاینت؛ سرور به‌طور ناخواسته open resolver نمی‌شود
- **داشبورد و متریک:** رابط وب، API، مسیر `/metrics` برای Prometheus
- **حریم خصوصی:** ناشناس‌سازی IP کلاینت و نگهداری لاگ فقط در حافظه
- **عملیات:** بارگذاری مجدد با `SIGHUP`، خاموشی تمیز، سرویس systemd، Docker

## شروع سریع
```bash
make build
./bin/ariadns                                  # فقط روی 127.0.0.1:5353
./bin/ariadns -config config.example.json -check
```
تست: `dig @127.0.0.1 -p 5353 example.com`

## نکات امنیتی
- گوش دادن روی آدرس غیر loopback نیازمند تنظیم `access.allow` است.
- باز کردن داشبورد روی شبکه نیازمند `web.token` با حداقل ۱۶ کاراکتر است.
